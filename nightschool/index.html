Method

How I run growth

Retention

Win-back email

I hold out 100 users from every win-back send and measure the campaign against that holdout, not against a before-and-after average.

Pricing

Paywall test

Before a paywall test ships, I set a guardrail: if new-cohort checkout-to-paid falls below 15%, the test rolls back automatically. No waiting for someone to notice.

Funnel

Sign-in leak

78% of visitors who reached sign-in left without trying the product. I rerouted the primary buttons to account creation instead, and measure the change on the step-by-step sign-in funnel.

Operations

The operating system

I run the company with an agent team. Nothing ships on the word of the agent that built it.
